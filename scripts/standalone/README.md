# Currency Converter / Конвертер валют

## Русский

1. **Распакуйте архив** в отдельную папку. Устанавливать Python не нужно.
2. **Настройте доступ к API:** скопируйте `.env.example` в `.env` в этой же папке (убедитесь, что файл не называется `.env.txt`). Откройте `.env` и замените значение `API_TOKEN` своим ключом [FreecurrencyAPI](https://freecurrencyapi.com/). Значение `API_URL` оставьте без изменений.
3. **Запустите конвертер из распакованной папки:**
   - **Windows:** дважды щёлкните `currency-converter.exe`.
   - **Linux:** выполните `./currency-converter` в терминале.
   - **macOS:** выполните `./currency-converter` в Terminal или откройте `Launch Currency Converter.command`.

Не публикуйте файл `.env`: он содержит ваш API-ключ.

## English

1. **Extract the archive** into a folder. You do not need to install Python.
2. **Configure API access:** copy `.env.example` to `.env` in the same folder (make sure the file is not named `.env.txt`). Open `.env` and replace the `API_TOKEN` value with your [FreecurrencyAPI](https://freecurrencyapi.com/) key. Leave `API_URL` unchanged.
3. **Run the converter from the extracted folder:**
   - **Windows:** double-click `currency-converter.exe`.
   - **Linux:** run `./currency-converter` in a terminal.
   - **macOS:** run `./currency-converter` in Terminal or open `Launch Currency Converter.command`.

Do not share the `.env` file: it contains your API key.
