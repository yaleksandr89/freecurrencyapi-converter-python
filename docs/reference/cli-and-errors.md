## Параметры запуска

Запускайте `index.py` из корня проекта через Python из `.venv`, созданного при установке. Примеры для Linux и macOS:

```bash
# Интерактивная конвертация на русском языке.
.venv/bin/python index.py

# Английский интерфейс.
.venv/bin/python index.py --lang en

# Справка без чтения .env и запроса к API.
.venv/bin/python index.py --help
```

В Windows PowerShell используйте `.\.venv\Scripts\python.exe` вместо `.venv/bin/python`. Порядок установки для обеих платформ описан в [руководстве](../guides/getting-started.md).

| Параметр | Поведение |
| --- | --- |
| `-h`, `--help` | Выводит справку на выбранном языке без чтения `.env` и обращения к API. |
| `--lang ru` | Выбирает русский интерфейс. Это значение по умолчанию. |
| `--lang en` | Выбирает английский интерфейс. Можно сочетать с `--help`. |

## Ввод и формат результата

CLI сначала загружает и выводит список валют. Коды указаны в квадратных скобках, названия приходят от FreecurrencyAPI.

1. Введите исходный код из списка, например `USD`.
2. Введите положительное конечное число. Для дробной части используйте точку, например `2.5`. Значения вроде `2,5`, `NaN` и `inf` отклоняются.
3. Введите один или несколько целевых кодов из того же списка, например `EUR,GBP`. Пустой элемент, в том числе после завершающей запятой, считается ошибкой.

CLI игнорирует регистр букв в кодах и пробелы по краям каждого кода. При ошибке ввода текущий запуск завершается. Чтобы повторить ввод, запустите команду снова.

Сумма преобразуется в `float` и округляется функцией `round` до трёх знаков после точки перед умножением на курс. Если округление даёт ноль или произведение выходит за диапазон конечных значений, CLI сообщает об ошибке.

Результат выводится в стандартный поток вывода, по одной строке на целевой код в порядке ответа API. Слева отображается округлённая исходная сумма без фиксированного числа знаков, справа — пересчитанная сумма с двумя знаками после точки. Пример на подставных курсах из тестов.

```text
2.5 USD = 2.00 EUR
2.5 USD = 1.25 GBP
```

## Запросы к FreecurrencyAPI

Оба запроса используют метод `GET`, базовый адрес из `API_URL` и передают `API_TOKEN` как параметр запроса `apikey`.

| Эндпоинт | Как его использует CLI |
| --- | --- |
| [`/currencies`](https://freecurrencyapi.com/docs/currencies) | Запрашивает список до первого приглашения к вводу. Проверяет, что у каждого кода есть непустое название. |
| [`/latest`](https://freecurrencyapi.com/docs/latest) | Запрашивает курсы после успешного ввода. Передаёт исходный код в `base_currency`, а целевые коды через запятую в `currencies`. Сумму CLI умножает на курсы локально. |

Клиент принимает HTTP 200 с непустым объектом `data` в JSON. Тайм-ауты составляют 4 секунды на установление соединения и 10 секунд на ожидание данных при чтении ответа. HTTP-перенаправления отключены. CLI требует курс для каждого целевого кода и использует только запрошенные курсы. Доступные валюты, значения курсов и лимиты запросов определяет FreecurrencyAPI.

## Коды завершения

| Код | Причина |
| --- | --- |
| `0` | Конвертация выполнена или выведена справка. |
| `1` | Ошибка конфигурации, запроса, ответа API или ввода, включая преждевременный конец ввода (EOF). |
| `2` | Некорректные аргументы CLI, например неизвестный параметр или неподдерживаемое значение `--lang`. |
| `130` | Пользователь прервал сеанс конвертации через Ctrl+C. |

## Сообщения об ошибках

Сообщения об ошибках выводятся в `stderr`. Их язык определяется параметром `--lang`. При неподдерживаемом значении `--lang` сообщение о языке выводится на русском.

| Категория | Причина |
| --- | --- |
| Конфигурация | `API_TOKEN` или `API_URL` отсутствует либо содержит только пробелы. |
| Сеть | Истёк тайм-аут или запрос завершился другой ошибкой, например ошибкой соединения. |
| HTTP | Сервер вернул статус, отличный от 200. CLI выводит этот статус. |
| Ответ API | Некорректный JSON, отсутствующий, пустой или неверный объект `data`, неверные сведения о валюте, отсутствующий, неположительный, нечисловой или неконечный курс для целевого кода. |
| Ввод | Неизвестный исходный или целевой код, пустой целевой элемент, некорректная сумма, округление суммы до нуля или переполнение при расчёте. |
| Завершение сеанса | Поток ввода закончился до получения всех значений или пользователь нажал Ctrl+C. |
