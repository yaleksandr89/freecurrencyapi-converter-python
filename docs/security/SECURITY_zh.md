## 支持范围

本政策适用于 `master` 分支中的当前代码。请报告 FreecurrencyAPI 密钥泄露、不安全的 API 响应处理，以及 CLI 输出或日志中的机密信息。

## 报告安全漏洞

如果 [Security 页面](https://github.com/yaleksandr89/freecurrencyapi-converter-python/security)显示 **Report a vulnerability**，请通过 GitHub Private Vulnerability Reporting 私下提交。

如果无法使用私密报告，请[创建一个不使用模板的问题](https://github.com/yaleksandr89/freecurrencyapi-converter-python/issues/new)，只请求私密沟通渠道。不要公开漏洞细节、利用步骤、密钥或 `.env` 内容。

私密报告中请注明提交 SHA、Python 版本、受影响的命令、可能的后果，并使用虚构数据提供最小复现步骤。
