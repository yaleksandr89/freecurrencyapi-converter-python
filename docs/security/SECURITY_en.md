## Supported scope

This policy covers the current code in `master`. Report exposed FreecurrencyAPI keys, unsafe API-response handling, or secrets accidentally printed to the CLI or logs.

## Reporting a vulnerability

If the **Report a vulnerability** button is available on the [Security tab](https://github.com/yaleksandr89/freecurrencyapi-converter-python/security), submit a report through GitHub Private Vulnerability Reporting.

If private reporting is unavailable, [open a blank issue](https://github.com/yaleksandr89/freecurrencyapi-converter-python/issues/new) requesting a private communication channel. Do not publish vulnerability details, exploit steps, keys, or `.env` contents.

In the private report, include the commit SHA, Python version, affected command, possible impact, and minimal reproduction steps using fabricated data.
