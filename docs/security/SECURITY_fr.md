## Périmètre de prise en charge

La politique couvre le code actuel de `master`. Signalez toute exposition de clé FreecurrencyAPI, gestion dangereuse des réponses API ou fuite de secrets dans la sortie CLI ou les journaux.

## Signaler une vulnérabilité

Si le bouton **Report a vulnerability** apparaît dans l’onglet [Security](https://github.com/yaleksandr89/freecurrencyapi-converter-python/security), utilisez GitHub Private Vulnerability Reporting.

Sinon, [créez une issue vide](https://github.com/yaleksandr89/freecurrencyapi-converter-python/issues/new) pour demander un canal privé. Ne publiez aucun détail de vulnérabilité, méthode d’exploitation, clé ou contenu de `.env`.

Dans le rapport privé, précisez le SHA du commit, la version de Python, la commande concernée, les conséquences possibles et les étapes minimales de reproduction avec des données fictives.
