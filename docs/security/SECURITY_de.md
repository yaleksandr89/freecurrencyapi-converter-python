## Unterstützter Bereich

Die Richtlinie gilt für den aktuellen Code in `master`. Melden Sie offengelegte FreecurrencyAPI-Schlüssel, unsichere API-Antwortverarbeitung oder Geheimnisse in CLI-Ausgaben und Protokollen.

## Sicherheitslücke melden

Falls auf der [Security-Seite](https://github.com/yaleksandr89/freecurrencyapi-converter-python/security) **Report a vulnerability** verfügbar ist, nutzen Sie GitHub Private Vulnerability Reporting.

Ist die private Meldung nicht möglich, [erstellen Sie ein leeres Issue](https://github.com/yaleksandr89/freecurrencyapi-converter-python/issues/new), um einen privaten Kommunikationskanal zu erfragen. Veröffentlichen Sie keine Schwachstellendetails, Angriffsschritte, Schlüssel oder `.env`-Inhalte.

Nennen Sie im privaten Bericht Commit-SHA, Python-Version, betroffenen Befehl, mögliche Folgen und minimale Schritte mit erfundenen Testdaten.
