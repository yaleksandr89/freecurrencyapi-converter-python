## Ámbito de soporte

Esta política cubre el código actual de `master`. Notifique la exposición de claves FreecurrencyAPI, la gestión insegura de respuestas API o la filtración de secretos en el CLI o registros.

## Cómo informar de una vulnerabilidad

Si la pestaña [Security](https://github.com/yaleksandr89/freecurrencyapi-converter-python/security) muestra **Report a vulnerability**, utilice GitHub Private Vulnerability Reporting.

Si no está disponible, [abra una incidencia sin plantilla](https://github.com/yaleksandr89/freecurrencyapi-converter-python/issues/new) solicitando un canal privado. No publique detalles de la vulnerabilidad, pasos de explotación, claves ni el contenido de `.env`.

Incluya en el informe privado el SHA del commit, la versión de Python, el comando afectado, las posibles consecuencias y pasos mínimos de reproducción con datos ficticios.
