## Périmètre de prise en charge

La politique couvre la version stable actuelle et le code actuel de `master`. Les versions antérieures ne sont pas maintenues séparément. Signalez toute exposition de clé FreecurrencyAPI, gestion dangereuse des réponses API ou fuite de secrets dans la sortie CLI ou les journaux.

## Signaler une vulnérabilité

Si le bouton **Report a vulnerability** apparaît dans l’onglet [Security](https://github.com/yaleksandr89/freecurrencyapi-converter-python/security), utilisez GitHub Private Vulnerability Reporting.

Sinon, demandez un canal privé dans [Discussions](https://github.com/yaleksandr89/freecurrencyapi-converter-python/discussions), sans révéler le motif de la demande ni les détails techniques. Ne publiez aucun détail de vulnérabilité, méthode d’exploitation, clé ou contenu de `.env`.

Dans le rapport privé, précisez le SHA du commit, la version de Python, la commande concernée, les conséquences possibles et les étapes minimales de reproduction avec des données fictives.

Coordonnez la publication des détails techniques avec le mainteneur après la disponibilité du correctif. Aucun SLA ni programme de récompenses n’est garanti.
