## Ámbito de soporte

Esta política cubre la versión estable actual y el código actual de `master`. Las versiones anteriores no se mantienen por separado. Notifique la exposición de claves FreecurrencyAPI, la gestión insegura de respuestas API o la filtración de secretos en el CLI o registros.

## Cómo informar de una vulnerabilidad

Si la pestaña [Security](https://github.com/yaleksandr89/freecurrencyapi-converter-python/security) muestra **Report a vulnerability**, utilice GitHub Private Vulnerability Reporting.

Si no está disponible, solicite un canal privado en [Discussions](https://github.com/yaleksandr89/freecurrencyapi-converter-python/discussions) sin revelar el motivo de la solicitud ni detalles técnicos. No publique detalles de la vulnerabilidad, pasos de explotación, claves ni el contenido de `.env`.

Incluya en el informe privado el SHA del commit, la versión de Python, el comando afectado, las posibles consecuencias y pasos mínimos de reproducción con datos ficticios.

Coordine la publicación de detalles técnicos con el mantenedor cuando haya una corrección. No hay SLA garantizado ni programa de recompensas.
