## Unterstützter Bereich

Die Richtlinie gilt für die aktuelle stabile Version und den aktuellen Code in `master`. Ältere Versionen werden nicht separat gepflegt. Melden Sie offengelegte FreecurrencyAPI-Schlüssel, unsichere API-Antwortverarbeitung oder Geheimnisse in CLI-Ausgaben und Protokollen.

## Sicherheitslücke melden

Falls auf der [Security-Seite](https://github.com/yaleksandr89/freecurrencyapi-converter-python/security) **Report a vulnerability** verfügbar ist, nutzen Sie GitHub Private Vulnerability Reporting.

Ist die private Meldung nicht möglich, bitten Sie in [Discussions](https://github.com/yaleksandr89/freecurrencyapi-converter-python/discussions) um einen privaten Kommunikationskanal, ohne den Grund oder technische Details offenzulegen. Veröffentlichen Sie keine Schwachstellendetails, Angriffsschritte, Schlüssel oder `.env`-Inhalte.

Nennen Sie im privaten Bericht Commit-SHA, Python-Version, betroffenen Befehl, mögliche Folgen und minimale Schritte mit erfundenen Testdaten.

Stimmen Sie die Veröffentlichung technischer Details nach Verfügbarkeit eines Fixes mit dem Maintainer ab. Es gibt kein garantiertes SLA oder Prämienprogramm.
