## Supported scope

This policy covers the current stable release and current code in `master`. Older versions are not maintained separately. Report exposed FreecurrencyAPI keys, unsafe API-response handling, or secrets accidentally printed to the CLI or logs.

## Reporting a vulnerability

If the **Report a vulnerability** button is available on the [Security tab](https://github.com/yaleksandr89/freecurrencyapi-converter-python/security), submit a report through GitHub Private Vulnerability Reporting.

If private reporting is unavailable, request a private communication channel in [Discussions](https://github.com/yaleksandr89/freecurrencyapi-converter-python/discussions) without disclosing the reason for the request or technical details. Do not publish vulnerability details, exploit steps, keys, or `.env` contents.

In the private report, include the commit SHA, Python version, affected command, possible impact, and minimal reproduction steps using fabricated data.

Coordinate public disclosure of technical details with the maintainer after a fix is available. There is no guaranteed SLA or bounty program.
