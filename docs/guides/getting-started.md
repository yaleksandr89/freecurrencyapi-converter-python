## Готовые сборки

Когда архив для вашей системы появится на [странице релизов](https://github.com/yaleksandr89/freecurrencyapi-converter-python/releases), скачайте и распакуйте его в отдельную папку. Python и `make` для готовой сборки не нужны.

1. В распакованной папке скопируйте `.env.example` в `.env` и запишите свой ключ FreecurrencyAPI в `API_TOKEN`. Оставьте `API_URL` как в шаблоне.
2. В Windows дважды щёлкните `currency-converter.exe`. В Linux и macOS запустите `./currency-converter` в терминале из этой папки. В macOS также можно открыть `Launch Currency Converter.command`.

Краткая инструкция на русском и английском есть во вложенном `README.md`.

## Что понадобится для установки из исходников

- Git для клонирования, Python 3.12 или новее и модуль `venv` с `pip`.
- Для конвертации — собственный ключ FreecurrencyAPI. Зарегистрируйтесь в сервисе и возьмите ключ в личном кабинете. Описание API доступно в [документации FreecurrencyAPI](https://freecurrencyapi.com/docs/).

## Получение исходников

Склонируйте репозиторий и перейдите в его корень, где находится `index.py`. Все последующие команды выполняйте из этого каталога.

```bash
# Скачать проект и перейти к файлам приложения.
git clone https://github.com/yaleksandr89/freecurrencyapi-converter-python.git
cd freecurrencyapi-converter-python
```

## Установка зависимостей

### Linux и macOS

Убедитесь, что `python3` указывает на Python 3.12 или новее и установлен `make`. Команда `make setup` создаёт `.venv`, если каталога ещё нет, и устанавливает проект и зависимости для разработки.

```bash
# Убедиться, что установлен Python 3.12 или новее.
python3 --version

# Создать .venv и установить зависимости для разработки.
make setup

# Создать локальную конфигурацию, не перезаписывая существующий ключ.
cp -n .env.example .env
```

Если подходящий интерпретатор доступен под другим именем, передайте его через `PYTHON`, например `make setup PYTHON=python3.12`. Этот параметр используется при создании окружения.

### Windows PowerShell

В примере `python` — установленный Python 3.12 или новее, доступный в `PATH`. Команды обращаются к интерпретатору из `.venv` напрямую, поэтому активация окружения и `make` не требуются.

```powershell
# Проверить версию Python.
python --version

# Создать окружение и установить зависимости для разработки.
python -m venv .venv
.\.venv\Scripts\python.exe -m pip install -r requirements-dev.txt

# Создать .env только при отсутствии этого файла.
if (-not (Test-Path .env)) { Copy-Item .env.example .env }
```

Для установки только проекта и его зависимостей замените `requirements-dev.txt` на `requirements.txt` в команде `pip install`. Для локальных проверок нужны зависимости из `requirements-dev.txt`.

## Настройка ключа и адреса

Откройте созданный `.env` в редакторе. Замените значение `API_TOKEN` своим ключом, а в `API_URL` оставьте базовый адрес API без пути конкретного эндпоинта.

```ini
API_TOKEN=your_api_token_here
API_URL=https://api.freecurrencyapi.com/v1
```

Храните ключ локально. Не добавляйте `.env` в Git и не публикуйте его содержимое в отчётах об ошибках. Переменные, уже заданные в окружении процесса, имеют приоритет над значениями из `.env`.

## Запуск и проверка

На Linux и macOS запустите конвертер через `make`:

```bash
# Русский интерфейс (по умолчанию).
make run

# Английский интерфейс.
make run CLI_LANG=en
```

В Windows PowerShell запускайте `index.py` через Python из созданного окружения:

```powershell
# Русский интерфейс (по умолчанию).
.\.venv\Scripts\python.exe index.py

# Английский интерфейс.
.\.venv\Scripts\python.exe index.py --lang en
```

После приветствия появится список валют. Если в нём есть `USD`, `EUR` и `GBP`, введите последовательно `USD`, `12.5` и `EUR,GBP`, нажимая Enter после каждого значения. При успехе CLI выведет по строке с результатом для каждой целевой валюты. Числа зависят от полученных курсов.

Проверить, что CLI запускается без ключа API и обращения к сети, можно через справку. В корне проекта выполните `.venv/bin/python index.py --help` на Linux/macOS или `.\.venv\Scripts\python.exe index.py --help` в PowerShell.

## Если запуск не удался

| Признак | Что проверить |
| --- | --- |
| Отсутствует `API_TOKEN` или `API_URL` | Проверьте имя файла `.env`, названия переменных и непустые значения. Если переменная уже задана в оболочке, проверьте её отдельно. |
| Сообщение с кодом HTTP | Проверьте базовый адрес, действительность ключа и доступный лимит запросов в кабинете FreecurrencyAPI. |
| Истекло время ожидания или не удалось отправить запрос | Проверьте правильность `API_URL` и доступность FreecurrencyAPI. |
| CLI отклонил ввод | Перезапустите конвертер. Возьмите коды из показанного списка, разделите целевые коды запятыми и введите положительную сумму с десятичной точкой. |

Подробные причины ошибок и коды завершения приведены в [справочнике команд и ошибок](../reference/cli-and-errors.md).

## Локальные проверки

После установки зависимостей для разработки проверьте проект из корня репозитория.

На Linux и macOS:

```bash
# Запустить тесты, Ruff и проверку установленных зависимостей.
make check
```

В Windows PowerShell:

```powershell
# Офлайн-тесты.
.\.venv\Scripts\python.exe -m pytest

# Стиль и форматирование.
.\.venv\Scripts\python.exe -m ruff check .
.\.venv\Scripts\python.exe -m ruff format --check .

# Согласованность установленных зависимостей.
.\.venv\Scripts\python.exe -m pip check
```

Тесты подменяют ответы или сбои FreecurrencyAPI и блокируют реальные HTTP-запросы. Проверки после установки зависимостей выполняются без сети и настоящего ключа. Доступность сервиса и действительность ключа проверяются при интерактивном запуске.
